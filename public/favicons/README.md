# Kido favicon assets

- `favicon.ico`: multi-size browser favicon (16, 32, 48)
- `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`: browser icon PNGs
- `apple-touch-icon.png`: 180x180 icon for Apple devices
- `android-chrome-192x192.png`, `android-chrome-512x512.png`: install/PWA icon sizes
- `kido-favicon-master.png`: high-resolution square master

Copy the favicon files into the public/static root served by your website. For Expo Web, update the HTML and web manifest to reference the relevant favicon and app-icon files as appropriate.
